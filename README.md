# 🌙 Ramazan İmsakiyesi

Ramazan İmsakiyesi, Türkiye şehirlerine göre namaz vakitlerini ve hava durumunu gösteren sade ve modern bir Android uygulamasıdır.
![Ramazan İmsakiyesi](/imsakiye-app-images/all.png)


## ✨ Özellikler

- 🇹🇷 81 il için namaz vakitleri
- 🌤 Anlık hava durumu
- 📖 Günlük ayet ve hadis
- 🕊 Minimal tasarım
- 📦 Widget desteği

## 🌤 Hava Durumu

Hava durumu verileri Open-Meteo API üzerinden alınmaktadır.
